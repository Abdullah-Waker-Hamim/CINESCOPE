CINESCOPE

One quick step 🎬

CineScope uses the free TMDB movie database. Paste your TMDB API Key (v3 auth) below.

  1. Create a free account at themoviedb.org
  2. Open Settings → API and request a Developer key
  3. Copy the API Key (32 characters) and paste it here
The key is stored only in your browser (localStorage). You can also put it in config.js.
